# Design

Дизайн-материалы TeamMaker. Структура повторяет архитектуру продукта: каждый вид спорта — отдельная папка со своими референсами и палитрами.

Дизайн-система общая для всего продукта — применяется к `web` и `mobile`.

## Структура

```
design/
├── table-tennis/          # Модуль настольного тенниса
│   ├── README.md          # индекс модуля
│   ├── foundations/       # токены: цвета, типографика
│   │   └── data/          # JSON-источники для generate-pdf.js
│   └── components/        # паттерны UI (карточки, ...)
└── utils/                 # Вспомогательные скрипты (генерация PDF)
```

Каждый новый вид спорта повторяет эту структуру: `<sport>/foundations/` для токенов, `<sport>/components/` для паттернов UI.

## Текущий статус

Активный модуль — `table-tennis`. Цветовая палитра готова, типографика готова, компоненты (карточки) в работе (см. Issue #1, #2).
