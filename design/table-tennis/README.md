# TeamMaker — Дизайн-референсы: Настольный теннис

Визуальные референсы для дизайн-системы модуля настольного тенниса. Используется как основа для web и mobile.
Связан с Issue #1 и Issue #2.

---

## Foundations

Базовые токены дизайн-системы — цвета и типографика.

- [foundations/colors.md](foundations/colors.md) — официальные цвета ITTF: стол, мяч, накладки, пол, ограждения (Butterfly, JOOLA, Stiga)
- [foundations/ui-palette.md](foundations/ui-palette.md) — три варианта базовой UI-палитры приложения (фон / карточки / акцент / текст) · [PDF](foundations/ui-palette.pdf)
- [foundations/typography.md](foundations/typography.md) — рекомендации по шрифтам, шкала размеров, альтернативы (Barlow Condensed + Inter)

---

## Components

Паттерны UI, построенные на foundations.

- [components/cards.md](components/cards.md) — референсы похожих продуктов, анатомия карточки турнира и профиля спортсмена, состояния статус-бейджа
