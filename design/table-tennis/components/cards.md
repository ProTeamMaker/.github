# Карточки турниров и профилей спортсменов — Настольный теннис

Референсы и рекомендации по карточкам для дизайн-системы TeamMaker.
Приоритет — тёмная тема, мобильное приложение.

---

## Что используют похожие продукты

| Продукт | Тип карточки | Что взять |
|---|---|---|
| Challonge | Карточка турнира | Статус-бейдж (Upcoming / In Progress / Complete), счётчик участников, формат сетки иконкой |
| Toornament | Карточка турнира | Обложка/баннер сверху, дата крупным шрифтом, компактный список рядом со списком дисциплин |
| Chess.com | Профиль игрока | Рейтинг рядом с именем, флаг страны, W/L/D в одну строку |
| Lichess | Профиль игрока | Минимализм: аватар, ник, рейтинг по режимам, без лишнего шума |
| Strava | Карточка активности/профиля | Крупная статистика (числа) над мелкими подписями, акцентный цвет только на одном показателе |
| ESPN | Карточка матча | Счёт крупно по центру, статус (LIVE / FINAL) цветным бейджем слева |

## Рекомендация для TeamMaker

Принцип: карточка — это **сканируемый блок**, где статус и ключевое число (счёт, рейтинг, дата) считываются за 1 взгляд, без чтения текста.

### Анатомия карточки турнира

| Элемент | Обязательность | Заметка |
|---|---|---|
| Статус-бейдж | Обязательно | Upcoming / Live / Completed — цвет из акцентной палитры (см. [ui-palette.md](../foundations/ui-palette.md)) |
| Название турнира | Обязательно | Barlow Condensed, см. [typography.md](../foundations/typography.md) (уровень H2) |
| Дата | Обязательно | Компактный формат, Label-размер |
| Формат / дисциплина | Опционально | Иконка (одиночный / парный разряд) вместо текста, если места мало |
| Число участников | Опционально | "24 участника" или иконка + число |
| Место проведения | Опционально | Только если релевантно (не для онлайн-турниров) |

### Анатомия карточки профиля спортсмена

| Элемент | Обязательность | Заметка |
|---|---|---|
| Аватар | Обязательно | Круглый, плейсхолдер — инициалы/силуэт на акцентном фоне при отсутствии фото |
| Имя | Обязательно | Barlow Condensed, Display/H1 в зависимости от контекста (полный профиль vs строка в списке) |
| Рейтинг (число) | Обязательно | Inter/Barlow, tabular-nums (см. типографику, роль `Score`) |
| Разряд/уровень | Обязательно | Определяет цвет карточки (см. вариант «Tier Card» ниже) |
| Спортивный бейдж | Опционально | Иконка вида спорта + короткий код (напр. «НТ») — точка расширения под другие модули (не только настольный теннис) |
| Клуб / город | Опционально | Label-размер, вторичный цвет текста |
| W/L или место в турнире | Опционально | Только в контексте конкретного турнира/сетки, не в общем профиле |

### Вариант «Tier Card» (в работе)

Референс: карточки игроков FIFA Ultimate Team / EA FC (рейтинг сверху слева, номер/позиция сверху справа, фото по центру, имя, флаг+страна, статистика снизу). Адаптация под TeamMaker — прямоугольник со скруглением вместо силуэта «щита», иерархия элементов сохранена.

- **Разряд определяет цвет всей карточки** — по аналогии с тем, как OVR определяет редкость/цвет карты в FUT. Пока три примерных тира: бронза / серебро / золото.
- Верх слева — числовой рейтинг (крупно, Barlow Condensed Bold).
- Верх справа — спортивный бейдж: иконка + короткий код вида спорта (заготовка под мультиспортовость платформы).
- Центр — аватар-силуэт (заглушка на фото).
- Низ — разряд (крупно, задаёт цвет карточки) с подписью сверху.
- Клуб/город — вместо флага страны из референса (у нас нет географической принадлежности спортсмена как в шахматах, зато есть клуб).

Статус: зафиксировано 3 тир-варианта в Figma, дальше дорабатывается по новым референсам от продакта.
Макет: [Figma — TeamMaker Карточка профиля спортсмена](https://www.figma.com/design/q05RfOeIA0Ti9GPAwXkniG)

Открытые вопросы:
- Иконка ракетки в бейдже пока не читается (похожа на каплю) — нужна перерисовка.
- Финальная палитра тиров (бронза/серебро/золото) — плейсхолдер, не сверялась с [ui-palette.md](../foundations/ui-palette.md).

### Состояния статус-бейджа

| Статус | Цвет (Вариант A) |
|---|---|
| Upcoming | Нейтральный / вторичный текст |
| Live | Акцент — оранжевый мяч `#F2901E` |
| Completed | Приглушённый вариант surface-цвета |

## Заметки

- Карточка турнира и карточка профиля должны использовать один и тот же паттерн "бейдж + заголовок + метрика", чтобы список турниров и список участников читались единообразно.
- Referencing-продукты выше — не для копирования 1:1, а как источник паттернов (что показывать крупно, что прятать за иконку).
- Референсы по навигации (следующий пункт чеклиста) повлияют на то, как карточки встраиваются в списки — держать в уме при вёрстке.
